# BPM Agent

This is an Agentic AI project for Business Process Management (BPM).

The idea is to use AI agents to help with things like:

* Searching and understanding business processes
* Finding process information and bottlenecks
* Analyzing process mining data
* Identifying possible improvements and automation opportunities
* Answering BPM-related questions
* Using Tavily to search for relevant information online

### Tech Used

* Python
* Streamlit
* OpenRouter
* Tavily
* Pandas

### Project Structure

```
agents/       → AI agents
services/     → Supporting services
data/         → Process and event-log data
memory/       → Execution context
tests/        → Test files
app.py        → Main Streamlit app
api.py        → API
config.py     → Configuration
```
